# 000｜基础教学视频定位与方案

来源：dontbesilent 于 X 发布的推文《绝大多数人是没有能力发基础教学视频的》（用户提供原文）

## 用户要完成的事
判断自己是否适合发布基础教学视频，并把一个已有的入门知识点改成能说明「为什么值得听我讲」且让零基础观众敢看下去的视频方案。

## 需要的输入
优先使用本轮对话已有材料；缺少时请用户提供：① 领域和准备教的入门知识点；② 能证明自己在这个领域有实践、成绩或持续产出的真实材料；③ 目标观众及其零基础时最担心什么；④ 发布后希望观众采取的下一步，以及现有产品或服务如何承接。没有证据或承接方式，可以明确写「暂无」，不要编造。

## 执行步骤
1. 先用已有材料还原用户的具体情境和目标，不把「基础」直接判成低价值，也不把身份或粉丝数当成教学能力的充分证明。若缺少会改变判断的关键材料，先问最少的问题；仍可基于已知信息开始初步诊断。
2. 对照原文的四层区分当前状态：① 只能做基础教学，尚无证据表明能处理更复杂的问题；② 能做较复杂内容，但话题过窄、难以获得广泛流量；③ 持续做工具型内容，有稳定流量且有匹配的商业承接；④ 已有可验证的深厚实力或公众认知，做入门科普能让观众感到有价值。逐层写出支持证据和缺口；证据不足时标为「待验证」，不强行归类。
3. 检查这条视频能否同时传递三项信息：我做科普并非只能做科普；我有足够的实力，值得信任；今天这条内容确实面向零基础，能听懂。分别指出可用的真实证据、具体呈现位置及可能让观众误解的表达。没有实力证据时，不写虚假的权威宣称。
4. 根据诊断给出一个具体的入门视频方案：选一个用户确实能讲清楚的最小问题，写出开头、教学顺序、可信度证据放在哪、零基础术语如何解释，以及结尾如何连接真实存在的下一步。若商业承接尚不存在，直接说明需要先验证，不凭空设计销量或转化承诺。
5. 最后给出一个发布前检查清单，指出最值得先补的一项证据或能力，并说明这条视频当前适合发布、需要修改后发布，还是暂不适合用该定位发布。

## 交付结果
输出「四层定位诊断」「三项信息检查」「一条基础教学视频方案」「发布前最先补的一项」四部分。每个判断标明依据来自用户材料还是基于材料所作的推断；缺少关键证据时保留待验证项。

## 验收标准
观众能看出这条视频具体教什么、为什么可以信任讲述者、零基础能否跟上；方案不把「名气大」误写成「教学一定更好」，不承诺流量或销量；所有实力与商业承接表述都能回到用户提供的事实。

## 适用边界
适用于已经有一个具体入门知识点，想决定是否以基础教学视频呈现的创作者。四层是分析视角，不是固定身份或流量公式。原推文没有提供平台算法、完整课程设计、转化率数据或「多少粉丝才有资格做科普」的门槛；不得由此推出保证涨粉、成交或教学质量的结论。
